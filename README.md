# 偏振仿真与马吕斯实验系统（lab）

多偏振片光强分析（马吕斯定律）与基于 BP 神经网络的马吕斯实验系统，纯前端单页应用。

**在线访问**：[lab.w-u.top](https://lab.w-u.top)

## 功能

- **多偏振片光强分析**：任意数量偏振片串联，实时计算透射光强（马吕斯定律）
- **偏振仿真实验**：交互式调节偏振片角度，观察光强变化曲线
- **BP 神经网络实验**：基于训练好的神经网络预测马吕斯实验结果，对比理论值

## 项目结构

| 文件 | 说明 |
|------|------|
| `index.html` | 主应用（单文件，内含仿真与神经网络推理） |
| `train.m` | MATLAB 脚本：训练 BP 神经网络 |
| `net.mat` | 训练完成的神经网络模型 |
| `net_visual.m` | MATLAB 脚本：网络结构可视化 |
| `CNAME` | 自定义域名（lab.w-u.top） |

## 本地使用

直接用浏览器打开 `index.html` 即可；如需重新训练网络，在 MATLAB 中运行 `train.m`。

## 部署

通过 GitHub Pages 发布，绑定域名 `lab.w-u.top`。
